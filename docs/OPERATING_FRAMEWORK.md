# NEVU HQ Unified Master System & Operating Framework — 1.1

The supplied framework is included here as the governing product specification. The application implements these key rules:

1. Approved stakeholder onboarding and Sole Administrator creation.
2. Nigeria → Africa is the primary market focus; global context is supporting context.
3. Capital protection is more important than aggressive profit-seeking.
4. Nine distinct agents operate within strict boundaries.
5. Agent outputs remain separate before any unified consideration.
6. Important responses use the 11-part standard output structure.
7. Confidence threshold for a strong recommendation is 70%.
8. Final Administrator authority is 60%; combined agent view is 40%.
9. No portfolio change is treated as approved without `Approved by [administrator username]`.
10. Approved decisions are archived; minutes confirm completion.
11. Personal AI is private to the Administrator.
12. Holding-to-Holding communication is separate from a private Holding Discussion Room.
